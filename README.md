# McKenzie River Guides Association website

Static site built with [Eleventy](https://www.11ty.dev/), hosted on Cloudflare Pages, edited in [Pages CMS](https://pagescms.org/).

```bash
npm install
npm run dev     # http://localhost:8768
npm run build   # output in _site/
```

- **Editing content:** sign in at app.pagescms.org (News & Stories, Events, Newsletters, festival block, officers & board, page text, site settings).
- **Guide and member lists:** edit the Google Sheet "MRGA Roster – Master" (association Google account). The website reads the public copy.
- **Rules and structure** for admins and AI tools: [AGENTS.md](AGENTS.md).
